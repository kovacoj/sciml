# Computing with thermal noise

This is an interactive adaptation of **Aifer et al., _Thermodynamic Linear
Algebra_**, [arXiv:2308.05660v2](https://arxiv.org/abs/2308.05660) (2024).
The paper is available under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
The exposition and browser experiments here are original; equations, protocols,
and complexity claims are attributed to the paper.

The central proposal is unusual: do not suppress physical fluctuations. Encode
a linear-algebra problem in a system of coupled harmonic degrees of freedom,
let the system thermalize, and read the answer from moments of its equilibrium
trajectory.

<Callout title="What this page demonstrates">
  The cells below simulate the paper's overdamped Langevin model in your browser.
  They explain the mechanism, but they do **not** benchmark thermodynamic
  hardware or independently verify the paper's speedup claims. Refreshing or
  changing a control produces a new stochastic trajectory.
</Callout>

## The equilibrium identity

For a symmetric positive-definite matrix `A` and vector `b`, define the
quadratic potential

```text
U(x) = 1/2 x^T A x - b^T x.
```

At inverse temperature `beta = (k_B T)^-1`, the Boltzmann density is
`p(x) proportional to exp(-beta U(x))`. Completing the square shows that it is Gaussian:

```text
x ~ Normal(A^-1 b, beta^-1 A^-1).
```

That single identity supplies two algorithms:

| Equilibrium observable | Linear-algebra result |
|---|---|
| First moment `<x>` | Solution `A^-1 b` |
| Centered second moment `beta Cov(x)` | Matrix inverse `A^-1` |

Ergodicity turns ensemble averages into time averages along one sufficiently
long trajectory. The first moment needs `d` integrator outputs; the complete
second moment needs `d^2` multiplier-integrator channels.

## Build a two-dimensional system

parameters. The page requires `A` to remain positive definite.

```python marimo
A_model = np.asarray(matrix_control.value, dtype=float)
b_model = np.asarray(force_control.value, dtype=float)
eigenvalues_model, eigenvectors_model = np.linalg.eigh(A_model)
is_spd_model = bool(np.all(eigenvalues_model > 0.0))

mo.stop(
    not is_spd_model,

    ).style({"color": "#b42318", "font-weight": "600"}),

covariance_exact = inverse_exact / beta_control.value

mo.md(
    f"""
    | Diagnostic | Value |

    | Condition number $\kappa$ | `{condition_model:.3f}` |
    | Exact solution $A^{{-1}}b$ | `({solution_exact[0]:+.4f}, {solution_exact[1]:+.4f})` |
    | Slow relaxation time $\gamma/\lambda_{{\min}}$ | `{gamma_control.value / eigenvalues_model[0]:.3f}` |
    """
```

## Watch equilibration

The paper analyzes both overdamped and underdamped motion. This demonstration
uses the overdamped Langevin equation (paper Eq. 27):

```text
dx = -gamma^-1 (A x - b) dt + sqrt(2 (gamma beta)^-1) dW_t.
```

The drift pulls the state toward `A^-1 b` while fluctuation-dissipation fixes
the noise amplitude. Euler-Maruyama is used here only to emulate that continuous
physical process on a digital computer.

```python marimo
beta_model = float(beta_control.value)
gamma_model = float(gamma_control.value)
dt_model = float(dt_control.value)
steps_model = int(steps_control.value)
burn_model = min(5_000, steps_model // 4)
rng_model = np.random.default_rng(230805660)

trajectory_model = np.empty((steps_model, 2), dtype=float)
trajectory_model[0] = solution_exact + np.array([7.0, 6.0])
noise_scale_model = np.sqrt(2.0 * dt_model / (gamma_model * beta_model))
for trajectory_index in range(1, steps_model):
    previous_state_model = trajectory_model[trajectory_index - 1]
    trajectory_model[trajectory_index] = (
        previous_state_model
        - (A_model @ previous_state_model - b_model)
        * dt_model
        / gamma_model
        + noise_scale_model * rng_model.standard_normal(2)
    )

samples_model = trajectory_model[burn_model:]
mean_estimate_model = samples_model.mean(axis=0)
centered_samples_model = samples_model - mean_estimate_model
inverse_estimate_model = (
    beta_model
    * centered_samples_model.T
    @ centered_samples_model
    / len(centered_samples_model)
)
linear_residual_model = float(
    np.linalg.norm(A_model @ mean_estimate_model - b_model)
    / max(np.linalg.norm(b_model), 1e-12)
)
inverse_error_model = float(
    np.linalg.norm(inverse_estimate_model - inverse_exact, ord="fro")
    / np.linalg.norm(inverse_exact, ord="fro")
)
```

```python marimo
    | Inverse row 1 | `({inverse_exact[0, 0]:+.4f}, {inverse_exact[0, 1]:+.4f})` | `({inverse_estimate_model[0, 0]:+.4f}, {inverse_estimate_model[0, 1]:+.4f})` |
    | Inverse row 2 | `({inverse_exact[1, 0]:+.4f}, {inverse_exact[1, 1]:+.4f})` | `({inverse_estimate_model[1, 0]:+.4f}, {inverse_estimate_model[1, 1]:+.4f})` |
    | Relative residual $\|A\bar x-b\|/\|b\|$ | `0` | `{linear_residual_model:.3e}` |

    """
)
```

The estimates are imperfect for two distinct reasons. Burn-in may end before
the slowest mode equilibrates, and successive samples are correlated. More
integration time gives more effective samples, but not one independent sample
per numerical step.

## Convergence is observable-dependent

The running mean estimates a first moment; the running covariance estimates all
second moments. The latter usually converges more slowly and requires many more
physical readout channels.

```python marimo
convergence_counts_model = np.unique(
    np.geomspace(100, len(samples_model), 80).astype(int)
)
mean_errors_model = []
inverse_errors_model = []
for convergence_count_model in convergence_counts_model:
    prefix_model = samples_model[:convergence_count_model]
    prefix_mean_model = prefix_model.mean(axis=0)
    prefix_centered_model = prefix_model - prefix_mean_model
    prefix_inverse_model = (
        beta_model
        * prefix_centered_model.T
        @ prefix_centered_model
        / convergence_count_model
    )
    mean_errors_model.append(
        np.linalg.norm(A_model @ prefix_mean_model - b_model)
        / max(np.linalg.norm(b_model), 1e-12)
    )
    inverse_errors_model.append(
        np.linalg.norm(prefix_inverse_model - inverse_exact, ord="fro")
        / np.linalg.norm(inverse_exact, ord="fro")
    )

convergence_figure, convergence_axis = plt.subplots(figsize=(8.5, 4.6))
convergence_figure.set_facecolor("#f4f0e8")
convergence_axis.set_facecolor("#f4f0e8")
convergence_axis.loglog(
    convergence_counts_model * dt_model,
    mean_errors_model,
    color="#167d9a",
    linewidth=2,
    label="first moment: linear system",
)
convergence_axis.loglog(
    convergence_counts_model * dt_model,
    inverse_errors_model,
    color="#cf7a24",
    linewidth=2,
    label="second moment: inverse",
)
convergence_axis.set_xlabel("post-burn-in integration time")
convergence_axis.set_ylabel("relative error")
convergence_axis.set_title("Running estimates from this trajectory")
convergence_axis.grid(alpha=0.18, which="both")
convergence_axis.legend(frameon=False)
convergence_figure.tight_layout()
convergence_figure
```

Do not expect either line to decrease monotonically: these are correlated,
stochastic estimates from one realization. The paper derives probabilistic
bounds rather than monotone guarantees.

## Why conditioning matters

In the eigenbasis of `A`, overdamped dynamics separate into independent modes.
A mode with eigenvalue `lambda_j` forgets its initial displacement as
`exp(-lambda_j t / gamma)`. The smallest eigenvalue is therefore the bottleneck.

Use this idealized mode explorer to isolate the effect of the condition number
`kappa = lambda_max / lambda_min` while fixing `lambda_max = 1`.


For the overdamped model, the paper bounds the equilibration time by a factor
proportional to `kappa tau_r` (up to logarithms), where
`tau_r = gamma / ||A||`. Its integration-time bounds scale as `kappa^2` for the
linear-system protocol and as `kappa` for inverse estimation, in addition to
dimension and error factors.

## Four thermodynamic primitives

The paper develops a hierarchy based on which equilibrium information is read:

1. **Linear system:** encode `b` as a constant force and estimate the mean.
2. **Matrix inverse:** set `b = 0` and estimate the covariance.
3. **Lyapunov equation:** choose correlated thermal noise with covariance `R`;
   the stationary covariance solves
   `A Sigma + Sigma A^T = 2 beta^-1 R`.
4. **Determinant:** infer a free-energy difference while changing one quadratic
   potential into another. For zero force,
   `Delta F = (2 beta)^-1 log(|A_2| / |A_1|)`.

The determinant protocol is qualitatively different. It uses work measurements
and the Jarzynski equality `exp(-beta Delta F) = <exp(-beta W)>`.
The paper warns that the direct exponential estimator is biased at finite
sample size and can converge slowly because rare trajectories dominate. It
points to Bennett and multistate Bennett estimators as better choices.

For the overdamped regime, Table I states the following full dependencies:

| Problem | Digital comparison in paper | Thermodynamic bound |
|---|---:|---:|
| Linear system | `O(min(d^omega, d^2 sqrt(kappa)))` | `O(d kappa^2 epsilon^-2)` |
| Matrix inverse | `O(d^omega)` | `O(d^2 kappa epsilon^-2)` |
| Lyapunov equation | `O(d^3)` | `O(d^2 kappa epsilon^-2)` |
| Matrix determinant | `O(d^omega)` | `O(d kappa log(kappa)^3 epsilon^-2)` |

Here `omega approximately 2.3` is the matrix-multiplication exponent used by the
authors. Their central asymptotic claim is a linear-in-`d` advantage when other
parameters are held fixed. Whether that becomes a practical wall-clock or
energy advantage depends on hardware and all omitted constants.

## What the comparison assumes

This is the most important qualification to the scaling story. The analytical
model assumes:

- Langevin dynamics accurately describe the device.
- `A` and `b` can be switched instantaneously.
- The quadratic potential can represent them with arbitrary accuracy.
- A convenient known Gaussian equilibrium state is available before a protocol.
- Analog multipliers and integrators operate in parallel as the system grows.

For numerical timing comparisons, the authors model an electrical device with
an `RC = 1 microsecond` timescale, 16-bit conversion, and 5,000 ADC/DAC
channels at 250 MSamples/s. They include an `O(d^2)` digital compilation step,
which was dominant in the investigated cases. They explicitly state that analog
imprecision was not included in those experiments.

The paper's simulations compare its hardware timing model against GPU conjugate
gradient and Cholesky calculations. They report increasing competitiveness at
larger `d` and `kappa`, especially when a quick approximate answer is useful;
the digital methods can ultimately reach higher precision. These are modeled
comparisons, not measurements from a large thermodynamic processor.

## Energy, time, and precision

Rescaling the force can apparently shorten averaging time, but it also deepens
the potential and costs energy. The paper reformulates this as a lower bound on
the energy-time product. In the overdamped model,

```text
E tau >= [2 kappa^2 d / (epsilon_x^2 (1 - P_epsilon))] beta^-1 tau_r.
```

Thus time is not a free resource that can be reduced indefinitely by increasing
signal amplitude. Precision is costly too: the probabilistic integration bounds
scale as `epsilon^-2`, as expected for sampling.

## What to take away

The paper's conceptual contribution is the mapping

```text
quadratic physics -> Gaussian equilibrium -> linear algebra from moments
```

Noise is useful because it explores the equilibrium distribution. The hierarchy
of first moments, second moments, and free-energy information yields progressively
richer algebraic objects. The strongest performance results remain conditional
on an analog hardware model and idealizations that real devices must confront.

The authors identify open questions around optimal energy-time tradeoffs,
higher-moment algorithms, analog error, and experimental scaling. They report a
separate eight-oscillator electrical demonstration of `8 x 8` matrix inversion
as an early hardware result, while leaving large-scale validation for future work.
