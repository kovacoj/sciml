The one-dimensional quantum harmonic oscillator is a compact test of how neural and finite-element methods recover an ordered spectrum:

$$
\left(-\frac{1}{2}\frac{d^2}{dx^2}+\frac{1}{2}x^2\right)\psi_n=E_n\psi_n,
\qquad E_n=n+\frac12.
$$

<Callout title="Precomputed experiment">
  Firedrake and PyTorch do not run in this page. The browser loads a versioned JSON dataset produced by the experiment script. Solver values, errors, timings, and sampled eigenfunctions are therefore reproducible static results rather than a client-side reimplementation. Direct FE is used as the numerical reference for the browser comparison. The known analytic harmonic-oscillator eigenpairs remain an independent validation target.
</Callout>

## Compare eigenstates

Select a formulation and an eigenstate. The Direct FE eigenpair is always shown as the numerical reference; it is therefore not a standalone selector option. The plot overlays the selected approximation with the Direct FE state on a common reference-energy baseline. Short neutral marks show the Direct FE energy ladder, while the colored dashed mark shows the selected method's computed eigenvalue.

```python marimo
selected_method_key_ho = method_control_ho.value
selected_method_ho = spectrum_data["methods"][selected_method_key_ho]
selected_style_ho = METHOD_STYLES_HO[selected_method_key_ho]

x_plot_ho = np.asarray(spectrum_data["coordinates"], dtype=float)


def normalize_state_ho(values):
    arr = np.asarray(values, dtype=float)
    norm = np.sqrt(max(float(np.trapezoid(arr ** 2, x_plot_ho)), 1e-15))
    return arr / norm


reference_states_ho = reference_method_ho["states"]
selected_states_ho = selected_method_ho["states"]

reference_psi_list_ho = []
selected_psi_list_ho = []
reference_energies_ho = []
selected_energies_ho = []

for idx in range(len(reference_states_ho)):
    ref_state = reference_states_ho[idx]
    sel_state = selected_states_ho[idx]
    
    ref_psi = normalize_state_ho(ref_state["values"])
    sel_psi = normalize_state_ho(sel_state["values"])
    
    ref_overlap = float(np.trapezoid(ref_psi * sel_psi, x_plot_ho))
    if ref_overlap < 0.0:
        sel_psi = -sel_psi
    
    reference_psi_list_ho.append(ref_psi)
    selected_psi_list_ho.append(sel_psi)
    reference_energies_ho.append(float(ref_state["eigenvalue"]))
    selected_energies_ho.append(float(sel_state["eigenvalue"]))

reference_ladder_ho = np.asarray(
    [s["eigenvalue"] for s in reference_method_ho["states"]], dtype=float,
)

potential_ho = 0.5 * x_plot_ho ** 2
```

## Method descriptions

### Direct FE reference

Direct FE assembles the CG2 Hamiltonian and mass matrices with Firedrake, then solves the generalized eigenproblem with SciPy. It provides a high-fidelity numerical reference against which the neural methods are compared; its accuracy is ultimately limited by the finite-element discretization and solver tolerance.

### Weak neural

Weak neural evaluates a coordinate MLP at finite-element degrees of freedom and minimizes an explicit test-space residual with an energy selector. The finite-element operators provide a strong optimization scaffold while preserving differentiability through the neural coefficient map.

### Strong PINN

Strong PINN minimizes the pointwise differential-equation residual using second coordinate derivatives. No finite-element assembly is required, but the optimization landscape is less constrained.

### Variational Rayleigh-Ritz

Variational Rayleigh-Ritz minimizes the neural Rayleigh quotient subject to projection against previously learned states. Sequential deflation in this setting can propagate inaccurate earlier states into later eigenstates.

## Interpretation

### Eigenvalue accuracy

All eigenstates are displayed on a shared vertical scale. The Direct FE reference states (solid) and the selected method states (dashed) can be compared visually across the entire spectrum.

### Eigenfunction accuracy

When the dashed curves overlap the solid reference curves, the method has recovered the eigenfunction shape. The reduced opacity allows all states to remain visible simultaneously.

### Timing

Computation times describe one workstation and reflect algorithmic overhead, architecture choices, and optimizer budgets. They should be compared relatively.

## Data and provenance

The page dataset lives at [`harmonic-oscillator-comparison.json`](../../../data/harmonic-oscillator-comparison.json). Keeping this compact artifact beside the site source has three advantages over a transient CI artifact: every deployment has a stable URL, changes are reviewable in Git, and the page remains functional after workflow artifacts expire.

The JSON records the generating command, source script, coordinate grid, eigenvalues, sampled normalized eigenfunctions, state-wise errors, and training times. Regenerate it when solver settings or implementations change; do not edit numerical values by hand.

## Limitations

- The curves are samples of precomputed finite-element or neural functions, not live solves.
- Timing values describe one machine and should be interpreted comparatively.
- Sequential neural deflation can propagate inaccurate earlier states into later states.
- A compact grid is used for browser delivery; full checkpoints and assembled matrices remain outside the website repository.

## Reproduction

The full precomputation source is retained at `notebooks/harmonic_oscillator_precompute.py`. It requires the native Firedrake environment and is intentionally not part of the browser export:
