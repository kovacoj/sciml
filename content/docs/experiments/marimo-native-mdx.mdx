# Native Marimo MDX Demo

This page evaluates the native `mdx-marimo` integration alongside the isolated
HTML/WASM iframe demonstration. The prose, navigation, and code cells all
belong to the same Fumadocs MDX document.

<Callout title="Experimental integration">
  This is a deterministic interface demonstration, not a research result. The
  browser initializes Pyodide before the controls become reactive.
</Callout>

## Reactive control

The first cell defines a slider. Its value is shared with the dependent cell
below even though ordinary MDX prose separates them.

```python marimo
import marimo as mo

mode = mo.ui.slider(
    start=1,
    stop=8,
    step=1,
    value=1,
    label="Eigenmode n",
    show_value=True,
)
mode
```

The exact eigenvalue of the one-dimensional Dirichlet Laplacian is evaluated
in a separate reactive cell.

```python marimo
import math

eigenvalue = (mode.value * math.pi) ** 2
mo.md(
    f"For mode **n = {mode.value}**, the exact eigenvalue is "
    f"**lambda = {eigenvalue:.8f}**."
)
```

## Comparison

The [iframe demonstration](./marimo-demo) remains the more isolated deployment:
it packages a complete notebook application under `public/notebooks/`. This
page instead lets reactive cells participate directly in the surrounding MDX
document and Fumadocs layout.
