# Interactive Laplacian Eigenmode Demo

This page demonstrates how interactive computational material can be included
inside the research notebook.

The problem is the one-dimensional Dirichlet eigenvalue problem

```text
-u''(x) = lambda u(x),  x in (0, 1),  u(0) = u(1) = 0.
```

Its exact eigenpairs are `lambda_n = (n pi)^2` and
`u_n(x) = sqrt(2) sin(n pi x)`.

The embedded marimo application compares the exact solution with a centered
finite-difference approximation. Change the eigenmode and grid resolution to
see the application update reactively.

## Scope of the demonstration

This page verifies the publishing and embedding pipeline. It is not a report
of the PINN, finite-element, CFD, or surrogate-optimization experiments.

Future interactive pages may consume compact result files generated by the
full research code, while expensive computation remains outside the browser.
