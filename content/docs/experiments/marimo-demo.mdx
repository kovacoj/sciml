This interactive page studies the one-dimensional Dirichlet eigenvalue problem

```text
-u''(x) = lambda u(x),  x in (0, 1),  u(0) = u(1) = 0.
```

Its exact eigenpairs are `lambda_n = (n pi)^2` and
`u_n(x) = sqrt(2) sin(n pi x)`. The native marimo cells below compare an exact
mode with its centered finite-difference approximation.

## Controls

Change the mode number or grid resolution. All dependent cells on this page
share one reactive namespace and update together.

```python marimo
import marimo as mo
import matplotlib.pyplot as plt
import numpy as np

mode_selector = mo.ui.slider(
    start=1,
    stop=8,
    step=1,
    value=1,
    label="Eigenmode n",
    show_value=True,
)

grid_selector = mo.ui.slider(
    start=20,
    stop=200,
    step=10,
    value=80,
    label="Interior grid points N",
    show_value=True,
)

mo.hstack([mode_selector, grid_selector])
```

## Finite-difference approximation

The centered second-difference operator is assembled on the interior grid.
The selected numerical eigenvector is normalized in the weighted discrete
`L2` norm and sign-aligned with the exact eigenfunction.

```python marimo
grid_size = int(grid_selector.value)
mode_number = int(mode_selector.value)

mesh_width = 1.0 / (grid_size + 1)
interior_points = np.arange(1, grid_size + 1, dtype=float) * mesh_width

main_diagonal = 2.0 * np.ones(grid_size) / mesh_width**2
off_diagonal = -1.0 * np.ones(grid_size - 1) / mesh_width**2
discrete_laplacian = (
    np.diag(main_diagonal)
    + np.diag(off_diagonal, k=1)
    + np.diag(off_diagonal, k=-1)
)

discrete_eigenvalues, discrete_eigenvectors = np.linalg.eigh(
    discrete_laplacian
)
numerical_eigenvalue = float(discrete_eigenvalues[mode_number - 1])
numerical_mode = discrete_eigenvectors[:, mode_number - 1].copy()

exact_eigenvalue = float((mode_number * np.pi) ** 2)
exact_mode_interior = np.sqrt(2.0) * np.sin(
    mode_number * np.pi * interior_points
)

numerical_mode /= np.sqrt(mesh_width * np.sum(numerical_mode**2))
weighted_overlap = mesh_width * np.dot(numerical_mode, exact_mode_interior)
if weighted_overlap < 0.0:
    numerical_mode *= -1.0

relative_eigenvalue_error = abs(
    numerical_eigenvalue - exact_eigenvalue
) / exact_eigenvalue
eigenfunction_l2_error = np.sqrt(
    mesh_width * np.sum((numerical_mode - exact_mode_interior) ** 2)
)

full_grid = np.concatenate(([0.0], interior_points, [1.0]))
exact_mode_full = np.sqrt(2.0) * np.sin(mode_number * np.pi * full_grid)
numerical_mode_full = np.concatenate(([0.0], numerical_mode, [0.0]))
```

## Mode and convergence

The second panel uses the closed-form eigenvalues of the centered
finite-difference operator to display grid convergence for the selected mode.

```python marimo
convergence_sizes = np.array([10, 20, 40, 80, 160, 320], dtype=int)
convergence_widths = 1.0 / (convergence_sizes + 1)
convergence_eigenvalues = (
    4.0
    / convergence_widths**2
    * np.sin(0.5 * mode_number * np.pi * convergence_widths) ** 2
)
convergence_errors = np.abs(
    convergence_eigenvalues - exact_eigenvalue
) / exact_eigenvalue

figure, axes = plt.subplots(nrows=1, ncols=2, figsize=(11.0, 4.2))

axes[0].plot(
    full_grid,
    exact_mode_full,
    label="Exact eigenfunction",
    linewidth=2.0,
)
axes[0].plot(
    full_grid,
    numerical_mode_full,
    "o--",
    label="Finite-difference eigenvector",
    markersize=3.0,
)
axes[0].set_xlabel("x")
axes[0].set_ylabel("u(x)")
axes[0].set_title(f"Eigenmode n = {mode_number}")
axes[0].grid(True, alpha=0.25)
axes[0].legend()

axes[1].loglog(
    convergence_sizes,
    convergence_errors,
    "o-",
    label="Relative eigenvalue error",
)
reference_scale = convergence_errors[0] * (
    convergence_sizes[0] / convergence_sizes
) ** 2
axes[1].loglog(
    convergence_sizes,
    reference_scale,
    "--",
    label="Second-order reference",
)
axes[1].set_xlabel("Interior grid points N")
axes[1].set_ylabel("Relative error")
axes[1].set_title("Eigenvalue convergence")
axes[1].grid(True, which="both", alpha=0.25)
axes[1].legend()

figure.tight_layout()
figure
```

## Interpretation

The centered finite-difference discretization is second-order accurate for
this smooth eigenproblem. Higher modes require finer grids because their
eigenfunctions oscillate more rapidly.
