# Pinned environment

* Base image: `dafoam/opt-packages:v5.0.0` (official precompiled DAFoam;
  contains OpenFOAM, PETSc, OpenMDAO, MPI, and the reverse-AD DAFoam build).
* Derived image: `sciml-dafoam-torch:v5.0.0` (adds PyTorch into an isolated
  venv with `--system-site-packages`; numpy/mpi4py/petsc4py/OpenMDAO/DAFoam
  are NOT reinstalled or upgraded).

Exact resolved versions are recorded after the image build in
`pip_freeze.txt` / `environment.txt` (generated by
`environment/environment_report.sh`, git-ignored).
