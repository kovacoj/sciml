## Current Focus

- Establish a repeatable notebook structure for numerical experiments.
- Test static search, navigation, tables, and code highlighting.
- Replace illustrative entries with reviewed research records.

## Planned Experiments

- Compare baseline eigensolvers on a controlled model problem.
- Define a surrogate-assisted optimization benchmark.
- Specify data and error measures for flow surrogates.
- Design a mixed-precision CFD verification study.

## Longer-Term Directions

- Connect numerical error estimates to learned surrogate uncertainty.
- Track computational cost alongside accuracy and robustness.

## Open Questions

- Which artifacts should be retained for every experiment?
- Which common metrics allow useful comparisons across methods?
- How should failed and inconclusive runs be documented?
