The one-dimensional quantum harmonic oscillator is a compact test of how neural and finite-element methods recover an ordered spectrum:

$$
\left(-\frac{1}{2}\frac{d^2}{dx^2}+\frac{1}{2}x^2\right)\psi_n=E_n\psi_n,
\qquad E_n=n+\frac12.
$$

<Callout title="Precomputed experiment">
  Firedrake and PyTorch do not run in this page. The browser loads a versioned JSON dataset produced by the experiment script. Solver values, errors, timings, and sampled eigenfunctions are therefore reproducible static results rather than a client-side reimplementation.
</Callout>

## Explore the spectrum

Use the counter or slider to move each sampled eigenfunction onto its computed eigenvalue level. Switch solvers to compare the shape and energy returned by each method. Short horizontal marks show the exact energy ladder; the dashed line is the selected solver's computed energy.

```python marimo
import io
import json
import marimo as mo
import matplotlib.pyplot as plt
import numpy as np
from pyodide.http import open_url

with open_url("/sciml/data/harmonic-oscillator-comparison.json") as data_stream:
    spectrum_data = json.load(data_stream)

method_keys = list(spectrum_data["methods"])
method_control = mo.ui.dropdown(
    options={spectrum_data["methods"][key]["label"]: key for key in method_keys},
    value=spectrum_data["methods"][method_keys[0]]["label"],
    label="Solver",
)
state_control = mo.ui.slider(
    start=0,
    stop=min(len(spectrum_data["methods"][key]["states"]) for key in method_keys) - 1,
    step=1,
    value=0,
    label="Eigenstate n",
    show_value=True,
)
mo.hstack([method_control, state_control], justify="center", gap=4)
```

```python marimo
selected_method_key = method_control.value
selected_method = spectrum_data["methods"][selected_method_key]
selected_state = selected_method["states"][int(state_control.value)]

x_plot = np.asarray(spectrum_data["coordinates"], dtype=float)
psi_plot = np.asarray(selected_state["values"], dtype=float)
energy_plot = float(selected_state["eigenvalue"])
exact_ladder = np.asarray(spectrum_data["exactEigenvalues"], dtype=float)
potential_plot = 0.5 * x_plot**2

figure, axis = plt.subplots(figsize=(9.2, 5.4), constrained_layout=True)
figure.set_facecolor("#f4f0e8")
axis.set_facecolor("#f4f0e8")
axis.plot(x_plot, potential_plot, color="#2f2b27", linewidth=2.0, label=r"$V(x)=x^2/2$")

for level_index, exact_energy in enumerate(exact_ladder):
    axis.hlines(
        exact_energy,
        -0.42,
        0.42,
        color="#8a8175",
        linewidth=1.3 if level_index == state_control.value else 0.8,
        alpha=0.85 if level_index == state_control.value else 0.35,
    )

method_color = selected_method["color"]
axis.axhline(energy_plot, color=method_color, linestyle="--", linewidth=1.0, alpha=0.55)
axis.plot(
    x_plot,
    energy_plot + 0.72 * psi_plot,
    color=method_color,
    linewidth=2.2,
    label=f'{selected_method["label"]}: n={state_control.value}',
)
axis.text(
    0.98,
    energy_plot,
    f"E = {energy_plot:.7f}",
    color=method_color,
    fontsize=9,
    va="bottom",
)
axis.set_xlim(*spectrum_data["domain"])
axis.set_ylim(0.0, float(exact_ladder[-1] + 1.5))
axis.set_xlabel("position x")
axis.set_ylabel("energy / shifted eigenfunction")
axis.set_title("Harmonic oscillator spectrum")
axis.grid(True, alpha=0.16)
axis.legend(frameon=False, loc="upper right")

svg_buffer = io.StringIO()
figure.savefig(svg_buffer, format="svg", bbox_inches="tight", transparent=True)
plt.close(figure)
responsive_svg = svg_buffer.getvalue().replace(
    "<svg ", '<svg style="width:100%;height:auto;display:block" ', 1
)
mo.Html(responsive_svg)
```

## Methods

- **Direct FE** assembles the CG2 Hamiltonian and mass matrices with Firedrake, then solves the generalized eigenproblem with SciPy.
- **Weak neural** evaluates a coordinate MLP at finite-element degrees of freedom and minimizes an explicit test-space residual with an energy selector.
- **Strong PINN** minimizes the pointwise differential-equation residual using second coordinate derivatives.
- **Variational** minimizes the neural Rayleigh quotient subject to projection against previously learned states.

## Data and provenance

The page dataset lives at [`harmonic-oscillator-comparison.json`](../../../data/harmonic-oscillator-comparison.json). Keeping this compact artifact beside the site source has three advantages over a transient CI artifact: every deployment has a stable URL, changes are reviewable in Git, and the page remains functional after workflow artifacts expire.

The JSON records the generating command, source script, coordinate grid, eigenvalues, sampled normalized eigenfunctions, state-wise errors, and training times. Regenerate it when solver settings or implementations change; do not edit numerical values by hand.

## Limitations

- The curves are samples of precomputed finite-element or neural functions, not live solves.
- Timing values describe one machine and should be interpreted comparatively.
- Sequential neural deflation can propagate an inaccurate earlier state into later states.
- A compact grid is used for browser delivery; full checkpoints and assembled matrices remain outside the website repository.

## Reproduction

The full precomputation source is retained at `notebooks/harmonic_oscillator_precompute.py`. It requires the native Firedrake environment and is intentionally not part of the browser export:

```bash
python -u notebooks/harmonic_oscillator_precompute.py \
  --method website --states 6 --fe-cells 128 \
  --weak-trial-degree 2 --weak-test-degree 3 \
  --weak-restarts 3 --output-dir harmonic-results

python scripts/import-harmonic-results.py \
  harmonic-results/harmonic-oscillator-comparison.json \
  public/data/harmonic-oscillator-comparison.json
```
