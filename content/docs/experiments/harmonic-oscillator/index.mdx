The one-dimensional quantum harmonic oscillator is a compact test of how neural and finite-element methods recover an ordered spectrum:

$$
\left(-\frac{1}{2}\frac{d^2}{dx^2}+\frac{1}{2}x^2\right)\psi_n=E_n\psi_n,
\qquad E_n=n+\frac12.
$$

<Callout title="Precomputed experiment">
  Firedrake and PyTorch do not run in this page. The browser loads a versioned JSON dataset produced by the experiment script. Solver values, errors, timings, and sampled eigenfunctions are therefore reproducible static results rather than a client-side reimplementation.
</Callout>

## Compare methods

Select a neural solver and eigenstate. The Direct finite element solution is always plotted as a thin reference line so the difference between the learned curve and the exact finite-element space is visible at a glance.

```python marimo
selected_label = method_control.value
selected_key = [k for k in NEURAL_KEYS if method_labels[k] == selected_label][0]
n = int(state_control.value)

selected_state = spectrum_data["methods"][selected_key]["states"][n]
ref_key = REFERENCE_KEY
ref_state = spectrum_data["methods"][ref_key]["states"][n]

x = np.asarray(spectrum_data["coordinates"], dtype=float)
selected_psi = np.asarray(selected_state["values"], dtype=float)
selected_e = float(selected_state["eigenvalue"])
ref_psi = np.asarray(ref_state["values"], dtype=float)
ref_e = float(ref_state["eigenvalue"])
exact_ladder = np.asarray(spectrum_data["exactEigenvalues"], dtype=float)
potential = 0.5 * x ** 2
method_color = spectrum_data["methods"][selected_key]["color"]
ref_color = spectrum_data["methods"][ref_key]["color"]

shift = 0.72

fig, ax = plt.subplots(figsize=(6.75, 3.6))

ax.plot(x, potential, color="#2f2b27", linewidth=2.0, label=r"$V(x)=x^2/2$")

for li, e_ex in enumerate(exact_ladder):
    lw = 1.3 if li == n else 0.8
    alpha = 0.85 if li == n else 0.35
    ax.hlines(e_ex, -0.42, 0.42, color="#8a8175", linewidth=lw, alpha=alpha)

ax.plot(
    x,
    ref_e + shift * ref_psi,
    color=ref_color,
    linewidth=1.4,
    label="Direct FE (reference)",
)

ax.axhline(selected_e, color=method_color, linestyle="--", linewidth=1.0, alpha=0.45)
ax.plot(
    x,
    selected_e + shift * selected_psi,
    color=method_color,
    linewidth=2.2,
    label=f"{selected_label} n={n}",
)

ax.set_xlim(*spectrum_data["domain"])
ax.set_ylim(0.0, float(exact_ladder[-1] + 2.2))
ax.set_xlabel("position $x$")
ax.set_ylabel("energy / shifted eigenfunction")
ax.set_title(f"Comparing {selected_label} against Direct FE")
ax.grid(True, alpha=0.16)
ax.legend(frameon=False, loc="upper right", fontsize=9)

as_responsive_svg(fig)
```

## Methods

- **Direct FE** assembles the CG2 Hamiltonian and mass matrices with Firedrake, then solves the generalized eigenproblem with SciPy.
- **Weak neural** evaluates a coordinate MLP at finite-element degrees of freedom and minimizes an explicit test-space residual with an energy selector.
- **Strong PINN** minimizes the pointwise differential-equation residual using second coordinate derivatives.
- **Variational** minimizes the neural Rayleigh quotient subject to projection against previously learned states.

## Data and provenance

The page dataset lives at [`harmonic-oscillator-comparison.json`](../../../data/harmonic-oscillator-comparison.json). Keeping this compact artifact beside the site source has three advantages over a transient CI artifact: every deployment has a stable URL, changes are reviewable in Git, and the page remains functional after workflow artifacts expire.

The JSON records the generating command, source script, coordinate grid, eigenvalues, sampled normalized eigenfunctions, state-wise errors, and training times. Regenerate it when solver settings or implementations change; do not edit numerical values by hand.

## Limitations

- The curves are samples of precomputed finite-element or neural functions, not live solves.
- Timing values describe one machine and should be interpreted comparatively.
- Sequential neural deflation can propagate an inaccurate earlier state into later states.
- A compact grid is used for browser delivery; full checkpoints and assembled matrices remain outside the website repository.

## Reproduction

The full precomputation source is retained at `notebooks/harmonic_oscillator_precompute.py`. It requires the native Firedrake environment and is intentionally not part of the browser export:

```bash
python -u notebooks/harmonic_oscillator_precompute.py \
  --method website --states 6 --fe-cells 128 \
  --weak-trial-degree 2 --weak-test-degree 3 \
  --weak-restarts 3 --output-dir harmonic-results

python scripts/import-harmonic-results.py \
  harmonic-results/harmonic-oscillator-comparison.json \
  public/data/harmonic-oscillator-comparison.json
```
